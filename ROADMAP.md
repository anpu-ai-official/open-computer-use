# Roadmap

Open Computer Use is deliberately narrow in v0.1: make one Mac/Claude Code/iTerm2/Chrome path excellent before broadening it.

## Near term

- Developer ID-signed and notarized v0.1 release
- Per-channel preview pinning and an optional multi-agent mosaic
- Descendant-target support for OOPIFs, workers, and service workers
- Richer trace interpretation and request-chain findings
- Better Cache Storage, IndexedDB record, WebSocket, and EventSource diagnostics
- Upgrade rollback and release-channel controls

## Later

- Multiple isolated Chrome profiles and clean-session workflows
- Firefox support where equivalent focus-safe transport exists
- Intel Mac evaluation
- Windows and Linux native-driver evaluation
- Additional agent runtimes without weakening the delegate-only context boundary

Roadmap items are directions, not commitments. Please open a feature request with a concrete workflow and acceptance criteria rather than a broad platform request.
