# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/) after the first stable release.

- Parallel inactive-tab automation in the existing Chrome profile.

- Isolated GUI and DevTools Claude Code operators.

- Deduplicated minimizable iTerm2 picture-in-picture preview.
- Self-contained installer, Homebrew formula renderer, doctor, repair, migration, and uninstall flows.
