# Support

Use GitHub Discussions for setup questions, workflows, and ideas. Use the bug-report issue form for reproducible defects and the feature-request form for scoped enhancements.

Before asking for help, run `open-computer-use doctor --deep` and check [Troubleshooting](docs/troubleshooting.md). Include versions and redacted diagnostics, but do not post raw browser artifacts, cookies, credentials, or personal data.

The project currently supports Apple-silicon macOS with Claude Code CLI, iTerm2, and Google Chrome. Requests for other platforms are welcome as roadmap input, but are not support incidents.
